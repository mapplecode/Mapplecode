## 🚀 Featured project

### 🔧 Field Technician App (React Native + Node.js)

A mobile app and backend for a property-management company's field technicians. It lets a
technician see their assigned work, check in at a property, log their time, and submit updates with
photos, with the office seeing the result in their own system straight away.

**What I built**

- 📱 **Expo / React Native app** (Android first) with a work queue, ticket updates, rehab and move-out
  forms, store runs and a room-by-room checklist
- 📍 **GPS features**: a distance check before an update, an "exception" flow when out of range,
  automatic clock in/out at a store using an OS geofence, and background location pings
- 📴 **Offline-first forms** that queue on the phone and send in order when the signal returns
- 🔐 **Secure sign-in**: the PIN is RSA-encrypted on the phone, and a stateless backend keeps sessions in
  signed JWTs
- 🔌 **Node.js / Express backend** that sits between the app and the company's API and AppFolio,
  with a webhook plus a scheduled pull to keep tickets current
- 🖼️ **Photo uploads** straight to storage with signed URLs, batched, retried and queued in the background
- 🚀 **CI/CD**: GitHub Actions workflows that build the signed Android APK and Play bundle without any
  paid build service, and deploy the backend to a VPS automatically on every merge

**Stack:** React Native · Expo · Node.js · Express · JWT · GitHub Actions · Gradle · PM2 · Linux VPS
